# Frontend do Planejamento Escolar

Esta pasta contém o aplicativo web em Angular. Para consultar os requisitos, as instruções de configuração e os comandos para executar o aplicativo completo com a API e o MongoDB, veja o [README do projeto](../README.md).

Nesta pasta, instale as dependências e inicie o frontend com:

```bash
npm ci
npm start
```

O frontend ficará disponível em [http://localhost:4200](http://localhost:4200). A API e o MongoDB também precisam estar em execução; consulte o README do projeto para ver as instruções.

Para compilar ou testar o frontend:

```bash
npm run build
npm test
```
